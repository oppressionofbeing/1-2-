Книжная полка
Учебное web-приложение «Читательский дневник»: учёт книг, прогресса чтения, оценок и читательских целей.
Стек: React, TypeScript, Vite, CSS. Данные пока демонстрационные (`src/data/mockBooks.ts`).
Запуск
Требуется Node.js 20.19+ (или 22.12+) и npm.
```bash
npm install        
npm run dev        
npm run build      
npm run lint       
```
Документация
Подробная спецификация проекта (пользователь, проблема, сущность, поля, страницы, сценарии, границы первой версии): docs/project-spec.md.
Структура
```
src/
├── data/mockBooks.ts      # демонстрационные книги
├── types/book.ts          # тип Book, статусы, жанры, подписи
├── utils/bookStats.ts     # расчёты: прогресс, скорость, «забытые» книги
├── App.tsx                # стартовый экран (дашборд)
├── App.css                # стили
└── main.tsx               # точка входа
docs/
└── project-spec.md        # спецификация проекта
```
